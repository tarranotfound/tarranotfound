# Contributing

Thanks for helping improve this learning project.

## Before submitting changes

1. Keep changes focused and explain the learning goal.
2. Build with `make` using a C++17 compiler.
3. Run `make test`.
4. Add regression coverage for behavior changes.
5. Update the README or relevant docs when commands or supported syntax change.

## Code style

- Prefer clear names and small functions.
- Use standard C++ facilities where practical.
- Validate user input and report actionable errors.
- Avoid introducing dependencies without documenting installation and build steps.
