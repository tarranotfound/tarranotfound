# Terminal Calculator (C++17)

A small interactive terminal calculator built step by step while learning C++.

## Build and run

```sh
make
./build/calculator
```

Enter expressions such as `8 + 3`, `12 / 4`, `2 ^ 8`, or `sqrt 81`.
Type `help` for commands, `history` to see previous calculations, `clear` to clear history, and `quit` to exit.

## Learning goals

- Standard input and output
- Variables, operators, and functions
- Parsing input and handling errors
- `switch`, loops, and conditionals
- Floating-point formatting
- Vectors and a small command-line interface
