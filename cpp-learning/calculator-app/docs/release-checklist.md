# Release checklist

- [ ] Build succeeds with a C++17 compiler.
- [ ] `make test` passes from a clean checkout.
- [ ] Manual regression checklist is reviewed.
- [ ] README examples match actual supported syntax.
- [ ] New limitations and dependencies are documented.
- [ ] No generated binary or temporary test files are committed.
- [ ] Changelog describes user-visible changes.

Do not mark planned TUI or parser features as complete until they exist and have been tested.
