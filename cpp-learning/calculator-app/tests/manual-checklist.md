# Manual regression checklist

- [ ] `8 + 3` prints `11.0000`.
- [ ] `12 / 4` prints `3.0000`.
- [ ] `2 ^ 8` prints `256.0000`.
- [ ] `sqrt 81` prints `9.0000`.
- [ ] `8 / 0` reports an error.
- [ ] `sqrt -9` reports an error.
- [ ] `history` lists successful calculations.
- [ ] `clear` empties history.
- [ ] `help` prints command guidance.
- [ ] `quit` exits cleanly.
- [ ] End-of-file exits without hanging.

This checklist complements `make test`; it is not an automated test runner.
