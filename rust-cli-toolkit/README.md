# Rust CLI Toolkit

A small interactive terminal program for practicing Rust fundamentals.

## Features

- Basic arithmetic with division-by-zero handling
- Celsius/Fahrenheit conversion
- Text reversal, character count, and word count
- In-session calculation history
- Unit tests for calculator operations

## Run

Requires a recent Rust toolchain with Cargo.

```sh
cargo run
```

## Test

```sh
cargo test
```

Choose an item from the numbered menu. Calculation history lasts for the current session only.
