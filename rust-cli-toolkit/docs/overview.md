# Project overview

Rust CLI Toolkit is a small, menu-driven terminal application for practicing core Rust concepts through practical utilities.

## Available tools

- Calculator for addition, subtraction, multiplication, and division
- Temperature conversion between Celsius and Fahrenheit
- Text inspection for reversal, character count, and word count
- In-memory calculation history for the current run

## Requirements

Install a recent stable Rust toolchain with Cargo. The project uses Rust edition 2024 and has no third-party dependencies.

## Quick start

```sh
cargo run
```

Run the test suite with `cargo test`.
