# Rust Lab — October 2026

Small standalone Rust examples covering core language building blocks.

## Run an example

Compile and run any file with the Rust compiler:

```sh
rustc 01_temperature.rs -o temperature
./temperature
```

For the unit-test example:

```sh
rustc --test 11_unit_tests.rs -o clamp-tests
./clamp-tests
```

Topics include branching, loops, collections, enums, structs, strings, paths, and tests.
