# Rust Learning

A practical Rust learning track focused on small programs, ownership, and clear error handling.

## Suggested sequence
1. Install Rust with rustup; verify rustc --version and cargo --version.
2. Learn variables, types, and control flow.
3. Practice functions, tuples, arrays, and slices.
4. Learn ownership, borrowing, and references.
5. Use String, Vec<T>, and HashMap<K, V>.
6. Model data with structs and enums.
7. Handle failures with Option, Result, and ?.
8. Write unit tests and build a small CLI.

## Projects
- hello-rust: first executable.
- variables: bindings and mutability.
- functions: typed functions and tests.
- ownership-demo: borrowing and references.
- guessing-game: interactive number game.
- todo-cli: in-memory task manager.

These are learning exercises, not production-ready applications.
